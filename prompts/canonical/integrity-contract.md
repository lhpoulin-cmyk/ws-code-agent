# Doc Writer conversational proposal v2 — integrity contract

Report integrity concerns separately from the conversational proposal. Use
only these categories:

- `confirmed_conflict`
- `apparent_conflict_requiring_authority_review`
- `unsupported_claim`
- `ambiguity`
- `no_material_issue_found`

Each finding contains a category, concise detail, a related source passage or
safe passage reference where practical, whether the issue blocks approval,
and what authority or clarification would resolve it where known.

Identify an issue, but do not repair it silently. A proposal may preserve
awkward or ambiguous wording when changing it would require an unsupported
decision.
